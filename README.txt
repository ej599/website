DAYA WEBSITE

Files:
- index.html: Main Daya website
- email-verified.html: Standalone email verification success page. It is intentionally not linked from the main website. Configure your authentication provider's email-confirmation redirect URL to this page when deploying.
- privacy.html: Privacy policy placeholder
- terms.html: Terms placeholder
- daya-logo.png: Daya logo asset

Preview locally by opening index.html or email-verified.html in a browser. For deployment, upload all files to the same site directory.
